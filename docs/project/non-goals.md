# Non-goals — V1

Things that are explicitly **not** in V1 after the social pivot.

## Product model non-goals

- Any feature that introduces brokerage, trading, investment advice products, exchange integrations, or speculative economy mechanics.
- Marketplace flows for buying/selling financial products, signals, or execution access.
- Growth loops based on vanity metrics as the primary value system (follower count as a core ranking signal).

## Financial and commerce non-goals

- Trade execution of any kind.
- Brokerage account linking.
- Portfolio, balances, positions, or PnL surfaces.
- Market quote terminals, tickers, watchlists, chart tooling, or asset-price speculation UIs.
- Donations, gifts, paid signal rooms, or transaction-based reputation.

## Platform non-goals

- Native iOS/Android apps in V1 (web only).
- Heavy i18n expansion in V1 (English-first).
- Experimental social-token economies or points economies tied to cash-out.

## Community quality non-goals

- Unmoderated anonymous posting.
- Engagement bait mechanics that optimize rage or doom scrolling.
- Opaque reputation scoring with no user-facing explanation.

## Permanent constraints

- The platform is identity/trust/community-first, not finance-first.
- Reputation must be built through contribution and consistency, not purchasable reach.

## How to handle scope creep

If a request conflicts with this file:

1. Stop.
2. Reference this file in the PR/chat.
3. Confirm intent with the maintainer.
4. If still needed, put it into a separately labeled post-V1 proposal.
