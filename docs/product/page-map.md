# Page Map (V1)

## Public

- `Home` (`/`)
  - Feed tabs
  - Community pulse strip
  - Ranked creator videos
- `Explore` (`/explore`)
  - Search + feed ranking
  - Live-now section
  - Topic quick filters
- `Community` (`/community`)
  - Post feed, category filters, sort, search, load-more
- `Communities landing` (`/communities`)
  - Hero, live strip, featured packs, trending discussions, ticker browse, new packs
- `Write post` (`/community/new`)
  - Rich text post editor, tags, cover image, draft/publish
- `Community post detail` (`/community/[postId]`)
  - Full post, upvote blocks, comments, replies, share actions
- `Live` (`/live`)
  - Active rooms
- `Video` (`/v/[videoId]`)
  - Player, creator context, like/dislike + share actions, expandable description, helpfulness vote, comments
- `Room` (`/room/[roomId]`)
  - Live viewer, helpfulness vote, chat/discussion
- `Pack home` (`/@[handle]`)
  - Hero (identity + verified badge + bio)
  - Pulse strip (next/live room, latest video, creator topic chips)
  - Timeline (creator-owned Pack posts, pinned-first)
  - Library tab (video grid as secondary surface)
- `Community principles` (`/pricing`)
  - Trust and contribution product principles
