# User Flows (V1 Social Pivot)

## Viewer discovery flow

1. Land on home feed.
2. Open a video or live room.
3. Leave helpfulness feedback and comments.
4. Navigate to creator profile and continue session.

## Creator publishing flow

1. Sign in.
2. Upload a video in studio.
3. Publish and verify watch-page quality.
4. Track engagement and reputation impact.

## Live host flow

1. Create room in studio.
2. Go live and moderate discussion.
3. End stream and direct users to recordings.

## Reputation progression flow

1. Create useful content.
2. Receive helpful votes and return viewers.
3. Improve consistency through frequent contributions.
4. Build profile trust over time via transparent behavior.

## Community participation flow

1. Discover relevant topics in explore.
2. Join recurring conversations via profile/live/video comments.
3. Return to trusted creators and active communities.
